# Datos del dashboard

El archivo trello.json se genera automáticamente mediante GitHub Actions.
No editarlo manualmente.

## Publicación segura desde Trello

- Añadir la etiqueta **PUBLICAR** a una tarjeta para permitir que su título, área,
  estado, fechas y enlace aparezcan en el catálogo público y en la cronología.
- Añadir **PUBLICAR-DETALLE** además de PUBLICAR para incluir su descripción.
- Añadir **PUBLICAR-IMAGENES** además de PUBLICAR para incluir imágenes adjuntas.

Las etiquetas deben existir en el tablero y aplicarse de forma deliberada.
Los comentarios, nombres de integrantes y datos de miembros no se publican.
Antes de autorizar una imagen o descripción, comprobar que no contenga datos
personales de estudiantes, familias u otra información confidencial.
